# Where New York lives

New York City's population density at every census from 1910 to 2020, drawn as ground that rises where more people live. A New York City version of the animated "Là où vit la France" density map.

- `index.html` — the page (WebGL; no libraries)
- `methodology.html` — sources, checks and caveats (generated by `scripts/build_methodology.py`)
- `assets/` — derived grids the page loads: `grids.bin.gz` (12 censuses of smoothed density), `land.png`, `nta.bin.gz`, `meta.json`

## Rebuild

Raw inputs live in `data/` (gitignored; NHGIS terms bar redistributing its tables).

```
python3 scripts/fetch_nhgis_historic.py   # 1910-1960 tract tables + boundaries; needs an IPUMS API key in ~/.nhgis_api_key
python3 scripts/build_grids.py            # also reads 1970-2020 NHGIS files from ../nyc-child-density/data
python3 scripts/build_places.py
python3 scripts/build_methodology.py
```

Borough boundaries: `data/boro_gthc-hcne.geojson` from NYC Open Data (`gthc-hcne`, City Planning, shoreline-clipped).

Method, checks and limits

How this was built

This explorer combines the city's agency performance dataset with the fiscal 2026 Mayor's Management Report. The open-data extract ends in March 2026; the completed year's values therefore come from the printed report where a row can be verified.

Sources and publication dates

  • Agency performance indicators: 768,409 rows in the September 2026 extract, covering 6,153 citywide and geographic series.
  • Fiscal 2026 report: 544 PDF pages. Links use the PDF page index, which differs from the printed page number.
  • MMR agency resources and PMMR agency resources: spending and staffing. Final prior-year actuals in the following PMMR replace provisional MMR actuals. Current-year plans are not used as actuals. These series currently stop at FY2025; FY2026 resources printed in the PDF have not been extracted.

The footer gives the data build date, not the date you opened the page. The JSON records the source PDF's SHA-256 checksum, source information, and the build timestamp. The city's Dynamic MMR is linked for reference and is not scraped.

Annual figures and time units

The June row supplies each fiscal-year slot from Open Data's year-to-date values. A fiscal-year slot is not a guarantee that the underlying observation covers July through June: school-year and calendar-year measures retain their reporting-period label in the indicator record.

Times named as minutes:seconds or hours:minutes are decoded from the portal's clock encoding: 9.42 becomes 9:42, not 9.42 decimal minutes. FDNY response times use that encoding based on their PDF labels. Titles naming only minutes, hours or days retain decimal units. Original clock encodings remain visible in the detail table. Invalid clock fractions are flagged, not silently converted.

How PDF rows are matched

The first pass requires agreement with at least three available FY2022–2025 values, within the report's displayed precision. Names help resolve clear ties. A second pass accepts small revisions only when histories are within 1.5%, names agree sufficiently, and the candidate is unambiguous. Five DOB complaint series use explicitly reviewed revisions: both the old and revised histories must match the values documented on PDF page 375. That review restores their FY2026 values without relaxing matching for unrelated rows.

The build now carries 2,042 matched records, including 2,006 FY2026 values and additional targets. A missing match is an extraction gap, not evidence that an indicator is absent from the report. New indicators without three years of history and larger revisions may remain unmatched. The tool is not a complete transcription of every printed table.

Matching numbers does not prove identical definitions. The report's explanations, changed methodologies, and footnotes still matter. For example, the four library six-day opening measures include branches closed for long-term renovations starting in FY2026. Those values remain visible, but comparisons across that documented break are excluded from scoring.

Revisions and source precedence

While FY2026 is unavailable as a completed year in Open Data, matched series use the printed report's available FY2022–2026 history. This avoids joining an old FY2025 denominator to a revised FY2026 figure. Open circles identify report-derived values. Original Open Data values that differ are retained in a separate comparison table; differences can be revisions or rounding. Older years remain from Open Data, so a boundary between publications remains and should be considered when interpreting long trends.

The report's desired direction governs FY2026 scoring and numeric target judgments. Historical year comparisons use the direction recorded for the compared year in Open Data. Eighteen conflicting direction labels were found in the audit, including unfilled early-childhood seats incorrectly labeled “higher is better” in the old metadata. Numeric targets, directional arrows, and unknown or unextracted targets are represented separately.

If Open Data later supplies a completed year, its available annual values take precedence over the PDF fallback. Matching, revisions, and coverage should still be reviewed after an upstream update; the build is not a general parser for future report layouts.

What the scoreboard measures

The scoreboard counts indicators moving toward or away from the city's desired direction. It is not an overall agency performance grade. Indicators are not independent, equally important, or equally representative of residents' experiences. A larger number of indicators does not by itself make an agency's score more reliable.

Percentage change uses the selected baseline. Exact equality is always unchanged, including at the “any change” setting. Changes smaller than the selected relative threshold are unchanged. Missing values, a zero baseline, flagged values, documented definition breaks, and no desired direction can prevent scoring. Zero-baseline values remain visible even though percentage change is undefined.

The minimum of ten scorable indicators for the agency table is a display rule, not a statistical confidence threshold. The annual overview uses that year's available indicators, so its composition can change over time. The current live/retired classification is applied throughout.

Outliers and comparability

  • Selected-year change follows the comparison controls. Other measures explicitly use the latest available readings or the whole comparable series.
  • Latest two readings can span a gap; the two years are labeled. They are not automatically described as a one-year change.
  • Percentage-point change ranks percentage indicators only. Raw dollars, counts and time units cannot be meaningfully ranked together.
  • Compounded annual change uses endpoints and elapsed years and requires positive values throughout. It does not establish that improvement was steady.
  • Fitted trend is a least-squares slope divided by the series mean. The fit indicates how well a straight line describes the data; low fit does not establish a particular cause.
  • Streaks and biggest one-year steps require adjacent years. Missing or flagged years break a streak.
  • Historical variability and unusual readings are descriptive, not significance tests or evidence of causation.

Flagged values remain in charts and tables but are excluded from derived statistics and scoring. A separate filter holds back near-zero baselines and changes of 100% or more. For the selected-year ranking it uses the selected baseline; for other rankings it uses the latest step. This is a sensitivity filter, not a finding that the city changed its counting rules. Geographic bars use one selected year and omit areas missing that year's observation.

What the ratios mean

The ratios are curated questions, not automatically discovered correlations. Both components must have a known matching reporting period and an unbroken overlap of usable years. True subset shares must stay between 0 and 100%; comparisons between incoming and outgoing flows may exceed 100%. These arithmetic checks cannot prove that two definitions or populations are compatible.

The taxi ratio includes initial inspections and retests, so it is an inspection-event pass share, not a first-pass rate. CCRB substantiated complaints divided by all case closures is not the official substantiation rate, which uses fully investigated complaints. The ratio entry links to a CCRB definition reference. Shelter exits divided by arrivals and violations closed divided by issues are flow comparisons, not cohort success rates. Library circulation per non-expired card is not circulation per person, and cross-system comparability has not been established merely by matching units.

Spending ratios use nominal dollars and cover an entire agency, not necessarily the cost of the activity in the denominator. Each entry shows its components, source links, periods and limitation. The comparison controls limit the displayed ratio years; missing endpoint data can make a ratio's visible span shorter.

Audit and checks

A September 18, 2026 audit compared all 49,219 nonempty historical cells in the original build with the current June source rows and found no disagreements after time conversion. It independently located 1,992 of the original 2,029 PDF matches using column coordinates; 36 had multiple numerical candidates, and one table without year headers was inspected visually. Those checks do not certify the identity of every ambiguous row. All 238 original plotted ratio calculations reproduced.

The audit nevertheless found consequential interpretation and software errors: reversed desired directions, unchanged values classified as deterioration at the zero threshold, mislabeled taxi and CCRB ratios, ignored final resource actuals, gaps counted as consecutive years, and displayed comparison years that disagreed with the calculation. These were corrected, with regression checks added. See the repository for the build scripts, tests and audit notes.

This project was initially built with Claude and subsequently audited and corrected with Codex under human direction. Automated checks reduce mistakes; they do not establish that every source figure, definition, or interpretation is correct. Check the linked report and notes before quoting a consequential finding.

Rebuilding

See the README for the complete command sequence. Python 3 and pypdf build the data; Node runs the browser-logic regression assertions. The PDF is cached unless --refresh is requested. Extracted text is reused only when its source checksum matches. Source tables are downloaded to temporary files and replace prior snapshots only after the expected row count is reached.

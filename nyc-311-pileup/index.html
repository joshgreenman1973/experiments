The city's public 311 data does not say who files a complaint, so these counts say how often an address was named, not how many people named it. What this counts

And please read this AI caution. The question and the choice of source are the author's (a human). The data pull, the code and the page were done by Anthropic's Claude Code under close direction. Quality control on this project: the quarterly pulls were summed and matched to the city's own row count exactly; addresses were cleaned by written rules, with entries that name only a street, park or airport set aside and counted; the timing analysis was rerun on the full record for each address after an exact-match query was found to miss older records stored with doubled spaces; and every number in the text on this page is computed from the published data files. The risks of using AI remain, and red flags are welcome.
